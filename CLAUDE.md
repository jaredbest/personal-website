# jaredbest.com

Personal site: React 19 + TypeScript + Vite, hosted on Netlify. Looks like an operator console; reads in plain English and German.

- Commands: `npm run dev`, `npm run build`, `npm test`, `npm run lint`, `npm run typecheck`.
- Content: `src/data/` (CV, skills, projects, posts), `src/content/posts/` (markdown), UI wording in `src/i18n/ui.ts`.
- Animations go through `src/lib/motion.ts` (`useSeen`, `useCardPlayback`, `prefersReducedMotion`); don't add new observers by hand.
- Ticonderoga map data is generated by `scripts/ticonderoga_edits.py`; never edit the JSON by hand.
- Before writing any copy, translation, comment or README text, load the `site-writing` skill in `.claude/skills/`.
- After changes, run `npm run typecheck && npm run lint && npm test && npm run build`.
- Pull requests: short title and a very brief description in plain English. No long change lists.
